Media file connections:
------------------------
while connecting we need to mention one location and allocate to the url ,here we required as same as static connections.

MEDIA_URL='/media/'
MEDIA_ROOT=os.path.join(BASE_DIR/'media')

add the media url and media root to the project urlpattern inside my urls.py

once the file is submitted the file can be store inside my project,so the file 
is known as a static file inside my project.

while connected the urlpattren we need to import static from django.contrib.urls.static.



while insert the media data via the html the data is not sended every time from html to views,
because some local systems html forms will be sended text data by default.
if we need to send file data we can mention enctype="multipart/form-data"

while read a file location in views we can use req.FILES.get('name')
